# Shades of Pink Theme Extension

This Gemini CLI extension provides a custom theme named "shades-of-pink-theme".

## Theme Details

This theme applies a harmonious palette of pink hues to the Gemini CLI interface, offering a visually delightful and personalized experience.

**Key colors include:**
-   **Primary Background**: Light blush pink (`#ffe4e1`)
-   **Primary Text**: Deep rose (`#c22d6e`)
-   **Secondary Text**: Muted plum (`#a25a77`)
-   **Link Color**: Hot pink (`#ff69b4`)
-   **Success Status**: Thistle (`#d8bfd8`)
-   **Warning Status**: Light pink (`#ffb6c1`)
-   **Error Status**: Tomato (`#ff6347`)
-   **Default Border**: Pink (`#ffc0cb`)
-   **UI Comment**: Coral pink (`#ffafbd`)

## Installation

To install this theme extension, place the `shades-of-pink-theme-extension` directory into your Gemini CLI extensions folder.

## Usage

Once installed, you can activate the "shades-of-pink-theme" through your Gemini CLI settings or preferences.
